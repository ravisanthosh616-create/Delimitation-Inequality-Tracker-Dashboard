# Delimitation Inequality Tracker Dashboard

## 📊 Project Overview

The **Delimitation Inequality Tracker Dashboard** is an Excel-based data analysis and visualization project designed to track and present inequality-related indicators associated with delimitation across different regions.

The dashboard converts structured data into interactive summaries, KPIs, comparisons, and visual insights to make complex information easier to analyze and understand.

## 🎯 Project Objectives

* Track key inequality indicators
* Compare indicators across regions
* Identify variations and patterns in the data
* Develop an interactive Excel dashboard
* Present important KPIs in a clear and accessible format
* Support data-driven analysis through visualizations
